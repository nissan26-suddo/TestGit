# Voice Quest

Voice Quest is a gamified English-speaking training experience inspired by the PTE Academic Speaking tasks. Conquer five magical chambers to unlock the Speaking Guardian while practicing fluency, pronunciation, and content skills.

## Features
- **Read Aloud Challenge** – Release magic power by narrating a highlighted passage.
- **Repeat Sentence Quest** – Match rhythm and pronunciation to energize an echo beam.
- **Describe Image Mission** – Speak vivid descriptions to fill the Creativity Meter.
- **Re-tell Lecture Arena** – Summarize an AI-spoken lecture and ignite Knowledge Orbs.
- **Answer Short Question Duel** – Respond quickly for sparks and bonus coins.

## Tech Notes
- Uses the browser Web Speech API for speech-to-text (and speech synthesis for prompts).
- Simple CSS animations reinforce the fantasy adventure theme.
- Local storage preserves progress, rewards, and skill averages across sessions.

## Getting Started
1. Open `index.html` in a modern Chromium-based browser with microphone access.
2. Allow microphone permissions when prompted.
3. Play audio prompts using the 🔊/▶/❔ buttons, then tap **Start** to record responses.
4. Watch the meters and magical feedback react to your performance!

> _Tip_: The experience uses heuristics for scoring and is intended for practice and fun, not as an official test score.
